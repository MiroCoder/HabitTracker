# HabitTracker
Java habit tracker for daily discipline: add habits, set priorities, track completion, sort, and search.
Features:
- add habits
- set priority: High / Medium / Low
- mark habits as completed
- sort by priority
- show done / not done habits
- calculate completion %
- classify the day: Perfect, Strong, System, Recovery, Zero
- search habits by name

Goal: practice Java Core, OOP, Collections, enums, methods, validation, and clean console logic.
